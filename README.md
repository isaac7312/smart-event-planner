Smart Event Planner

Smart Event Planner is a full-stack web application that helps event organizers create and manage events, while users can view and book available events.
The system is designed to be simple, secure, and easy to use.

Features

Secure organizer login using JWT authentication
Create, edit, and delete events
View all events and event details
Track bookings and event capacity
Clean and responsive user interface

Tech Stack

Frontend:
Angular, TypeScript, HTML, CSS

Backend:
Node.js, Express.js, TypeScript

Database:
MySQL

How to Run the Project
Backend
cd backend
npm install
npm run dev


Frontend
cd frontend
npm install
ng serve


Security

Password hashing using bcrypt
JWT-based authentication
Protected routes using middleware
